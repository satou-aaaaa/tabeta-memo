# たべたメモ

食べたものを記録して、カロリーと栄養の過不足を見るアプリです。無料・登録なし・広告なし。記録はスマホやパソコンの中だけに置きます。

https://satou-aaaaa.github.io/tabeta-memo/

- 食品 2,538 品の栄養値：文部科学省「日本食品標準成分表（八訂）増補2023年」
- 1日の目安：厚生労働省「日本人の食事摂取基準（2025年版）」
- 減量の目標：日本肥満学会「肥満症診療ガイドライン2022」の「3〜6か月で今の体重の3%」
- 写真から探す：端末の中の画像 AI（Apple MobileCLIP S0・Transformers.js）で、写真に近い料理の候補を出す。写真は外へ送らない
- 前の日と同じ食事を1回で入れる・量をあとから直す・体重の30日グラフ・見やすさの設定
- 次の食事の献立のおすすめ・コンビニで選ぶときの組み合わせ・近くのコンビニやスーパー（OpenStreetMap）

開発のしかたは [AGENTS.md](AGENTS.md)。
